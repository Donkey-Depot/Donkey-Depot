# Security Policy

## Supported Versions

We take the security of Donkey Depot seriously. Security updates are provided for the versions listed below.

| Version | Supported |
| ------- | --------- |
| 5.1.x   | ✅ |
| 5.0.x   | ✅ |
| 4.0.x   | ✅ |
| < 4.0   | ✅ |

Only versions explicitly marked as supported are eligible for security updates. Users are encouraged to upgrade to a supported version whenever possible.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Donkey Depot, please report it responsibly.

**How to report:**
- Contact the development team privately rather than disclosing the vulnerability publicly.
- Include a clear description of the vulnerability, steps to reproduce it, and any relevant screenshots, logs, or proof-of-concept details.
- Do not publicly disclose the vulnerability until the development team has had an opportunity to investigate and address it.

**What to expect:**
- **Acknowledgment:** We aim to acknowledge your report within 72 hours.
- **Investigation:** The development team will assess the severity, impact, and validity of the report.
- **Updates:** We aim to provide progress updates at least every 7 days while the issue is under active investigation.
- **Resolution:** If the vulnerability is accepted, we will work toward a fix and communicate the remediation plan when appropriate.
- **Declined reports:** If the report is not accepted, we will explain the reasoning whenever possible.

**Scope**

Please report vulnerabilities that could compromise user accounts, data confidentiality, data integrity, application availability, or other security controls.

Please avoid accessing, modifying, or deleting other users' data, disrupting services, or exploiting vulnerabilities beyond what is necessary to demonstrate the issue.

**Responsible Disclosure**

We appreciate security researchers and community members who help us protect Donkey Depot and its users. We ask that all reports be made in good faith and that researchers allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

Thank you for helping keep Donkey Depot secure.
